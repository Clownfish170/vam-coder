### 4.3 命题 1 三层拆分

**（1）数学前提（成立条件）**

```
full_files_in_messages 语义 = 按归一化路径、按消息顺序后写覆盖的 dict。
若 P(H) 对每条路径至少保留 H 中该路径最后一次完整 FILE 块，
则 full_files_in_messages(P(H)) = full_files_in_messages(H)。
```

- 阶段 A `tracker_from_history` 与阶段 B `verify_omissions_in_messages` **共用** `full_files_in_messages` → 候选证明与校验提取池在前提满足时不变。

- PreSendCheck：`ok / missing_or_mismatch / reasons / visible_hashes / et·cf` 在提取池与 disk_sha 不变时逐字段相等。

- 单测：`test_full_files_extract_equal`、`test_tracker_and_presend_equal`、`test_first_last_equivalence`、`test_vso_modules_untouched_by_sah` 等。

## 5. S2 Obligation Ledger Audit

### 5.1 义务解析（`obligations.py`）

| 项 | 实现 |
|---|---|
| 解析方式 | 子句级正则：编辑动词 + `file.py` + 可选符号；**完全确定性、零 LLM** |
| 强/弱动作 | 弱动词（实现等）仅在抽出符号时入账，避免参考句误报 |
| 否定句 | `不要修改/勿改` 跳过 |
| 多文件 | **只取子句首个文件**为主目标（防永不关闭） |
| 解析不出目标 | `kind=raw`，**恒未结**，≤48 字渲染 |
| 可能漏检 | 非 `.py` 文件、无编辑动词的义务、多子句只抓首文件、符号正则过窄 |
| 可能误报 | 强动词+点名文件即入账，即使后续语义未完成 |
| LLM | **无** |

### 5.2 状态派生 — 最高优先级问题

```text
is_open():
  raw / 无 targets     → True（恒未结）
  add（有符号）         → 任一目标文件中符号词界缺席 → 未结；否则结清
  add（无符号）         → 回退文件哈希未变 → 未结
  modify               → _sha_untouched：任一目标文件 sha 仍等于提出时 → 未结
                         否则（该文件哈希已变）→ 结清
```

**文件哈希变化会直接导致修改型义务结清 —— 是。**

由此产生的**错误结清**路径（论文未覆盖）：

| 场景 | 行为 | 风险 |
|---|---|---|
| 改同文件无关代码 | sha 变 → **结清** | **高**：目标函数未改也算完成 |
| 只改部分要求 | sha 变 → **结清** | **高** |
| 改错作用域/文件 | 主目标未动但另一 targets 文件变了？仅当**所有** targets 都变才… 实际 `_sha_untouched`：**任一** target sha≠raise → 结清 | **高**（多目标时一动即关） |
| 改后回滚 | 结清后再改回 → 已结清不恢复 | 中 |
| 文件重命名/删除 | sha_now 缺失 → `sha_now.get(f)==raise` 为 False → **结清**（错误） | **高** |
| 多义务同文件 | 一改全关 | 高 |
| 义务冲突 | 无检测 | 中 |

**新增型**：

| 场景 | 行为 |
|---|---|
| 同名符号在错误文件 | 若 targets 指对文件则仍开；指错则可能永远开或误关 |
| 错误作用域/错误类 | **词界全文匹配 → 可能误结清** |
| 签名不正确 | **不检查 → 可能误结清** |
| 功能未完成 | **不检查 → 可能误结清** |

**结论**：S2 **不是**语义任务完成检测；是**粗粒度启发式**。论文 §3.4「未结判定为确定性规则：新增型=符号在源码缺席、修改型=提出后文件哈希未变」——字面与代码一致，但若读者理解为「正确跟踪任务是否完成」则**过强**。贡献段「S2 从工作区状态派生并保留未结义务…不漂移、不说谎」中「不说谎」**与错误结清冲突**。

### 5.3 状态分类

| 状态 | 存在？ | 触发 | 结束 | 恢复 | 渲染 | 失败 |
|---|---|---|---|---|---|---|
| OPEN（未结） | **是**（`is_open==True`） | 解析成功且条件未满足；或 raw | 见下 | **无**（无 UNRESOLVED/重开） | `open_lines` 渲染 | — |
| CLOSED（已结） | **是**（`is_open==False`） | add：符号出现；modify：任一 target sha 变 | — | **无**（不因回滚重开） | 不渲染 | — |
| UNRESOLVED | **否** | — | — | — | — | — |
| FAILED/CONFLICT | **否** | — | — | — | — | — |

**只有二元 OPEN/CLOSED。** 对「无法判断是否语义完成」的情况，实现选择**过早 CLOSED**而非 UNRESOLVED。  
**是否需要 UNRESOLVED**：若论文要主张正确义务跟踪 → **需要**（至少：修改型在「仅哈希变」时标 UNRESOLVED 或要求符号/差异指纹）；若论文降级为「启发式提醒行」→ 可不改代码，但必须改表述。  
**渲染条件**：仅 `is_open`；模型请求成功步才 `parse_obligation` 入账（`run_p1_v12.py` L535–540，跳发步不入账）。

### 5.4 S2 实验归因

**臂设计（实际）**：

| 臂 | 机制 |
|---|---|
| F | 基座 VSO/O′ |
| PROJ | F + **S1** |
| SAH | F + **S1 + S2** |
| （不存在） | **F + S2 only** |

- 预注册主比较：H-E1/E2（SAH−F）、H-E3a/b、H-E4（PROJ−F）。**无 SAH−PROJ，无 F+S2。**  
- **SAH−PROJ 只能事后探索**（本次只读重算，见 §7.4）：DS prompt **+46.0** [−11.2, +115.2]（S2 账本略贵、CI 含 0）；Qwen **−12.3** [−48.2, +20.4]（CI 含 0）。ESR 两模型均非劣方向可过，但**均未预注册**。
