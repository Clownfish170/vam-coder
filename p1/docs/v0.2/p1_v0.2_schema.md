# P1-v0.2 数据 Schema

版本：`p1-v0.2`；对应任务集 `p1-v0.2.0`。所有 JSON 为 UTF-8；缺失字段用
`null` 并在同级 `*_note` 说明，**禁止**用估算值冒充服务端数据。

## 1. run_meta.json

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `run_id` | str | 与 run 目录名一致 |
| `p1_version` | str | `"v0.2"` |
| `started_at` | iso8601 | UTC |
| `task_set_version` / `frozen_at` | str | 来自 tasks.json |
| `tasks_sha256` | hex | tasks.json 整文件哈希 |
| `script_sha256` | obj | `run_p1.py` / `p1_common.py`（及清单中的其他脚本） |
| `eval_dir_sha256` | obj | `"<episode>/<step>" → 目录哈希` |
| `project_dir_sha256` | obj | `"<episode>" → 目录哈希` |
| `manifest_check` | obj | `{path, matched, mismatches[]}`；无清单时 `matched=null` |
| `git_rev` / `git_branch` / `git_dirty` / `p1_untracked_in_git` | | P1 仓库 Git 状态 |
| `model` | obj | 见下 |
| `endpoint` | str | OpenAI 兼容 base（含 /v1） |
| `server_probe` | obj | `/version`、`/models`、`/props` 原样 JSON 或 null + `error[]` |
| `dry_run` | bool | |
| `temperature` / `seed` / `max_tokens` / `budget_tokens` / `max_history_chars` | | 请求与路由参数 |
| `history_policy` | str | 统一策略描述 |
| `rep` | int | 重复编号 |
| `baselines` / `baseline_rotation` / `episodes` | | |
| `config_digest` | str | P0 AppConfig 摘要 |
| `env.python` / `env.platform` / `env.dependencies` / `env.hardware` | | 依赖与硬件；取不到 = `"unknown"` |
| `capabilities` | obj | 能力边界声明（含 REUSE_KV 代理限制） |
| `frozen_rules` | list | 预注册规则原文 |
| `timing_definitions` | obj | 计时字段定义（与 protocol 一致） |

### model 子对象

| 字段 | 说明 |
| --- | --- |
| `model_requested` | 请求体 `model` |
| `served_models` | `/v1/models` 返回的 id 列表或 null |
| `gguf_path` | 服务端标识指向 .gguf 时记录；否则 null |
| `gguf_sha256` | `{path, sha256, note}`；`--no-hash-model-file` 或文件不可读 = null |
| `quantization_tag` | 从路径/模型名解析（如 `q6_k`）；失败 `"unknown"` |
| `server_args` / `server_ctx` / `parallel_slots` | 可探测则填（/props），否则人工参数或 `"unknown"` |

## 2. per_step.csv 列

身份：`episode, step, baseline, rep, baseline_order_index, model`
质量：`eval_success`（1/0/空=dry-run）
token：`prompt_tokens, completion_tokens, total_tokens, usage_source
(api|estimate|none), context_tokens_est, history_tokens_est, n_messages,
router_est_tokens`
计时：`t_initial_sync_ms, t_sync_ms, t_route_ms, t_assemble_ms, t_model_ms,
t_eval_ms, t_step_ms`
机制：`n_expand, n_reuse_kv, n_compress, n_drop, n_stale, n_unverified,
n_tombstoned, reuse_decisions, reuse_omitted, reuse_omitted_files,
reuse_omitted_bytes, reuse_without_omission, expand_included_bytes`
上下文：`context_file_blocks, context_summary_blocks, context_chars,
response_chars`
其他：`applied_files, rejected_files, history_pairs_dropped, error`

## 3. 每步文件

| 文件 | 内容 |
| --- | --- |
| `context.txt` | 方法装配的 CONTEXT 段原文 |
| `prompt.txt` | 发送的最后一条 user 消息 |
| `messages.json` | 完整 messages 数组（system+历史+本轮） |
| `request.json` | 见下 |
| `response.txt` | 模型回包文本（真实运行） |
| `apply.json` | `{applied[], rejected[{path,reason}]}` |
| `eval_output.txt` | pytest 原始输出 |
| `result.json` | CSV 行 + `decisions[]` + `raw_usage` + `assemble_notes` + `history_policy` |

### request.json

| 字段 | 说明 |
| --- | --- |
| `model_requested` / `response_model` | 请求名 / 回包 `model` 字段 |
| `endpoint` / `params` | 端点与 `{temperature, seed, max_tokens, stream}` |
| `started_at` / `ended_at` / `latency_ms` / `http_status` | 请求级时间与状态；异常时 `http_status` 可为 null，`error` 非空 |
| `messages_path` / `messages_sha256` / `n_messages` | 可审计副本与哈希（sha256 为 sort_keys JSON） |
| `history_tokens_est` / `context_tokens_est` | chars/4 **估算**，仅用于分解 |
| `usage_raw` | 服务端 usage 对象原样；无则 null |
| `usage_source` | `api` / `estimate` / `none`（dry-run） |
| `usage_note` | 固定说明：缺失字段不伪造 |
| `auth_headers_logged` | 恒 false（本客户端不记录头、不发送密钥） |

## 4. episode_summary.json（新增字段）

`rep, baseline_order_index, t_initial_sync_ms, t_episode_ms, t_steps_sum_ms,
reuse_decisions_total, reuse_omitted_bytes_total, history_pairs_dropped_total`

## 5. baseline_orders.json

`[{episode, episode_index, offset, order[]}, …]`

## 6. 清单 manifests/<name>.json

`manifest_version, created_at, task_set_version, tasks_sha256, script_sha256,
test_sha256, eval_dir_sha256, project_dir_sha256, eval_file_sha256,
project_file_sha256`（后两者为逐文件哈希，便于定位变更文件）。

## 7. 失败与空值约定

- 模型 HTTP 失败：`error="model_error: …"`，`usage_source="none"`，
  `usage_raw=null`，`eval_success` 空。
- dry-run：`error="dry_run: …"`，模型/评测字段全空，仍写 messages/request。
- 服务端不提供 cached_tokens：`usage_raw` 中自然缺失该键；分析时不得补估。
