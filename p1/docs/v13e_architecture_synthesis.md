## 1. 完整架构（两层）

```text
┌─ 基座层（冻结）──────────────────────────────────────────┐
│  v12F + VSO/O′ 选择性交付                                │
│  · 每步：build_plan(must/ET/related) → assemble          │
│  · 阶段A O′ 候选证明（从"将发送的历史"提取）              │

│  S1 状态投影：历史 assistant FILE 块按路径折叠            │
│    档位旋钮 last / first_last(定稿) / first_last2 /       │
│    last2 / last3；保留集合必含"每路径末版"                │
│  S2 义务账本：窄口径解析未结义务 → TASK/CONTEXT 间一行    │
│    add 型=符号缺席；modify 型=提出后文件未再改；raw 兜底  │
└──────────────────────────────────────────────────────────┘
      ↓ 不变：VSO/O′ 语义 · must/ET 全文 · 任务集 · 评测口径
```

## 2. 创新点（可主张 / 不可主张）

### 可主张（按可辩护度排序）

| # | 主张 | 论文表述要点 | 硬证据 |
| --- | --- | --- | --- |
| **N1** | **证明保持的状态投影** | 投影"每路径保留末版"与 O′ 校验的后写覆盖语义**同构** ⇒ 删冗余对可见性证明逐字段零影响；把安全证明内建进记忆压缩，而非压缩后补检 | DS504 离线重放 **504 集 / 2808 步，`full_files_in_messages` + `PreSendCheck` 字段全等 0 失败**；单测 |
| **N2** | **记忆 = 未结义务，而非输出流水账** | 现行 harness 丢弃全部历史指令；账本以**确定性判定**（符号缺席 / 提出后未改）让未结要求常驻，零 LLM | dose_D06 同批：**PROJ 0.33 → SAH 1.00**（账本救回）；驱动案例 ind_L06a（step3 义务蒸发 → 终步 NO_EDIT 级联） |
| **N3** | **零 LLM · 确定性 · 可复现** | 纯函数、纯规则、可单测可回放；与 LLM 摘要/反思类记忆形成方法学对照 | 全部模块零推理调用；163 单测 |
| **N4** | **结构级而非 token 级折叠** | 主动引 AGORA（2605.26596）"agent 场景 token 级压缩破坏动作语法"作为设计依据：只整块保留/折叠 FILE 块，不触碰块内 token | 设计约束 + 代码结构 |

### 不可主张（红线，写进 Limitations/Related）

1. 「上下文压缩」本身不新：LLMLingua（2310.05736，20×）· Selective Context（2310.06201，50%）· Lexical 压缩（2609.13154）。
2. 不与 MemGPT / Reflexion / Voyager 比"记忆更强"；不主张通用长期记忆、LLM 反思、技能合成。
3. TrawMem（2610.36918）报 token −5–13%：量级相近、**对象不同**（报告上下文 vs 多轮代码轨迹），只并列不压过。
4. **双 Token 无独立收益**（冻结报告：−1.1%、Holm p=0.109、非劣 FAIL）；另记口径保留意见：**该专项的双 Token 臂缺 VSO，与带 VSO 的 v12F 直接比不公平**——论文只作实现细节与边界披露。
5. 不主张 KV 显存/延迟收益（无张量实测）。
