## 1. 研究主题（统一，不靠改名造新）

**Safety-Constrained Memory Addressing and Adaptive Context Assembly for Code Agents.**

三机制：

| 机制 | 含义 | 状态 |
| --- | --- | --- |
| **Symbol ID** | 低成本记忆定位（内部 Index，符号寻址） | **已实现**（P0/V1.1） |
| **O′** | 可见性约束下的安全省略 | **已实现**（V1.1） |
| **Task-aware Assembly** | 任务感知上下文粒度 FULL/DIGEST/NONE + 预算/ must_full | **待实现**（V1.2） |

改名（如 Progressive Expansion → Adaptive Context Assembly）**只**用于更准确描述 harness 单步粒度选择，**不**构成新贡献。

## 2. 已实现 / 待实现 / 待验证 / 未证明

| 类别 | 内容 |
| --- | --- |
| 已实现 | 符号索引与 validity；O′ 安全省略；审计与成本账本；V1.0/V1.1 基线可复现 |

| **尚未证明学术新颖性** | 相对 hierarchical RAG / code-agent memory 的不可替代差异 |

## 3. 概念邻域（非文献综述）

| 方向 | 典型思路 | 关系 | 重叠风险 |
| --- | --- | --- | --- |
| 层次/分级检索 RAG | coarse→fine | 粒度选择相似 | **高**：审稿人可能视为 RAG 变体 |
| 代码库智能体 + 工具读文件 | 模型决定读什么 | 我们默认 harness 确定性 | 中 |
| 上下文压缩/摘要 | 摘要替源码 | V1.2 Digest **不**替编辑目标 Full | 中 |
| KV/前缀缓存 | cached_tokens/显存 | 我们分列且不宣称 VAM KV | 低（若纪律执行） |
| Memory agents | 跨会话记忆 | 范围更窄（episode/步内代码记忆） | 中 |
| Progressive disclosure | 多轮披露 | V1.2 为 **单步粒度**，非多轮 PE | 需表述准确以免误导 |
