## 1. 研究问题

在 Dual-Layer Token 架构下，V1.1（可见性安全省略 + EMC + 审计/账本）能否：

- **RQ-A（准确率）**：相对 `vam_coder_v1.0` 非劣；  
- **RQ-B（效率）**：相对 `memory_off` 降低 Total Tokens per Successful Episode；  
- **RQ-C（安全）**：Invalid/Stale 注入率 ≈ 0，且不存在伪造记忆。

## 5. 指标定义

主准确率：

- **Episode Success Rate (ESR)**：两步均 `eval_success=1`。

效率：

- **TPSE** = \(\sum\) (prompt+completion) / 成功 episode 数  
- Input/Output Tokens、Prefill 近似 = prompt_tokens（API）  
- Latency：`t_model_ms` 墙钟  

记忆质量：

- **Retrieval Success Rate (RSR)**：EMC `need=true` 的步中，计划文件均出现在注入上下文或可见性证明中的比例  
- **Invalid/Stale Retrieval Rate (ISR)**：注入文件中 hash 失配或 validity∈{stale} 且仍被当作可信完整内容注入的比例（V1.1 目标 0；EXPAND 重读后按当前源码注入则不计 invalid）  
- **Memory Retrieval Overhead**：`t_route_ms + t_assemble_ms + index_ms` 与注入字符  
- **Verified Safe Omission (VSO)**：O′ 通过的省略文件计数  

**禁止**：用 step pass rate 替代 ESR；用 `cached_tokens` 替代 TPSE/VSO。

## 6. 预注册判定标准（锁死）

设 \(E_{10}, E_{11}, E_{off}\) 为对应条件 ESR；\(T_{11}, T_{off}\) 为 TPSE。

### 6.1 准确率非劣效（相对 V1.0）

\[
E_{11} - E_{10} \ge -\Delta_{ESR},\quad \Delta_{ESR}=0.10
\]

（10 个百分点非劣界；1.5B 方差大，过紧无意义。）

### 6.2 准确率改善的参考线（报告用，非门禁）

期望 \(E_{11} \ge E_{10} + 0.05\)；若 \(E_{11} < E_{off} - 0.15\) 判 **不可接受**（显著伤害任务）。

### 6.3 效率收益门禁（相对 memory_off，成功 episode 口径）

\[
T_{11} \le (1-\delta)\,T_{off},\quad \delta=0.05
\]

**且** §6.1 成立。若 ESR 非劣但 TPSE 未降：结论为“安全修复成功、效率未证实”，**不得**宣称架构有效。

### 6.4 安全门禁

- ISR = 0（V1.1 注入路径）  
- 任意 `INSUFFICIENT_CONTEXT` 必须出现在 audit；不得静默编造源码  

### 6.5 消融（R=1，固定 8 任务子集，见 §8）

| 消融 | 关闭项 | 比较 |
| --- | --- | --- |
| A1 | 无 EMC（每步全 L2） | vs 默认 V1.1 → 是否需要控制器 |
| A2 | 无 L1（本就默认关） | 确认 L1 不得擅自开启 |
| A3 | 无 version/hash 门控（危险，仅 dry 诊断） | vs 默认 → 验证必要性 |
| A4 | 无回退（验证失败仍省略） | vs 默认 → 验证回退必要性 |

消融不进入主门禁，但必须写入验收报告。
