## 0. 归因分类（本阶段采用）

| 类 | 名称 | 操作定义 |
| --- | --- | --- |
| 1 | 信息缺失 | 模型可见上下文/历史中 **缺少** 完成任务所需的当前源码或依赖信息 |
| 2 | 检索错误 | EMC/索引选错文件、漏选编辑目标、错误省略本应注入的文件 |
| 3 | 协议违例 | 上下文充分，模型未遵守 FILE/NO_EDIT 输出协议或未按任务编辑 |
| 4 | 模型推理错误 | 协议正确但语义/算术/依赖理解错误 |
| 5 | 架构额外开销 | 记忆管线导致 token/延迟上升或成功路径变差，而非缺信息 |

## 2. 逐案归因（证据）

### 2.1 v1_RUR02 — 协议违例（主）

**F1** V1.1 step1 context 含完整 `hot.py, stable_a.py, stable_b.py`（`.../v1_RUR02/vam_coder_v1.1/steps/step1/context.txt`）。  
**F2** response = `NO_EDIT`（`response.txt`），eval 失败（`hot()==2` 未改）。  
**F3** memory_off 同任务同结构全源输入 **通过**（validation CSV / 对照 run）。  
**F4** step2 省略 `stable_b.py`（VSO≥1），仍注入 `hot.py, stable_a.py`；仍 `NO_EDIT`。

| 归因 | 判定 |
| --- | --- |
| 信息缺失 | **否（主路径）**：编辑目标 hot.py 在 context 中完整可见 |
| 检索错误 | **否**：目标文件在 plan EXPAND 且出现在 context |
| 协议违例 | **是（F1–F3）** |
| 推理错误 | 次要 |
| 架构开销 | step2 多注入略少 token，未阻止失败 |

**H1**：v1.1 短 banner `[ctx] v1.1` 与 memory_off 的 MODE 行分布差，可能影响 1.5B（未消融，H）。  
**H2**：非正式推测“stable 省略致失败”被 F4 **削弱**——省略后仍 NO_EDIT，且 step1 未省略也失败。

### 2.2 v1_RUR03 — 协议违例为主

**F5** step1/2 context 均含 `core.py` 全源。  
**F6** step1 `NO_EDIT`；step2 有 FILE 输出但仍 eval 失败（需对照 response 语义）。  
**F7** memory_off 本子集 step 失败（ESR 任务级 ✗）——任务本身对 1.5B 难。

| 归因 | 判定 |
| --- | --- |
| 信息缺失 | **否**（core 可见） |
| 检索错误 | **否** |
| 协议违例 | **是（step1 NO_EDIT）** |
| 推理错误 | step2 可能叠加（H，需逐字节 diff response） |

### 2.3 v1_DUP01 — 协议/推理（非信息缺失）

**F8** V1.1 step1/2 context 均含 `mathx.py` 与 `textx.py`（双文件可见）。  
**F9** v1.0 正式曾仅注入 mathx 导致 textx 缺失（见 `v1.1_failure_analysis.md` DUP01）；**V1.1 已消除该信息缺失**。  
**F10** V1.1 step1 仍 `NO_EDIT`；step2 编辑行为仍导致 eval 失败（validation response）。

| 归因 | 判定 |
| --- | --- |
| 信息缺失（v1.1） | **否** |
| 检索错误（v1.1） | **否**（双文件均 EXPAND） |
| 协议违例 | **是**（step1 NO_EDIT） |
| 推理错误 | **是**（step2 改错/改不全，F10） |

### 2.4 v1_STM02 — 推理错误

**F11** step1 成功；step2 context 含 `bill.py, fee.py` 全源。  
**F12** step2 输出编辑了 bill/fee，但 `due_fast` 语义错误（漏 `+1` 类，与正式诊断同型）。  
**F13** memory_off 同步 step2 通过。

| 归因 | 判定 |
| --- | --- |
| 信息缺失 | **否** |
| 检索错误 | **否** |
| 协议违例 | **否**（有 FILE 输出） |
| 推理错误 | **是（主）** |
| 架构开销 | 无证据表明导致算错 |
