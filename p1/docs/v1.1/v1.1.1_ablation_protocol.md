## 0. 目的

在 **相同模型、任务、种子、环境** 下，分离 V1.1 各机制对 ESR / TPSE / 安全指标的贡献，回答：

1. 外部记忆控制器（EMC）是否有独立价值？  
2. 安全回退（O′ 失败 → EXPAND）是否必要？  
3. 关闭安全机制是否“换”来 token/准确率（**仅隔离诊断**）？

**不**在本阶段启动任何消融 run。

## 2. 实验组定义

| 组 | ID | 名称 | 行为 | 部署可用性 |
| --- | --- | --- | --- | --- |
| A | `memory_off` | 无记忆全源 | 每步全 workspace .py | 正式对照 |
| B | `vam_coder` | V1.0 | 冻结 v1.0 路径（`run_p1.py`） | 正式对照 |
| C | `vam_coder_v1.1` | V1.1 默认 | EMC + O′ + 回退 + 审计 | **候选正式** |
| D | `vam_coder_v1.1_no_emc` | 关 EMC | **每步对全部索引文件 EXPAND**（无 REUSE 候选、无 need=false）；仍保留装配层审计/账本 | 消融诊断 |
| E | `vam_coder_v1.1_no_fallback` | 关安全回退 | 计划为 REUSE_KV 时 **无视 O′**，直接省略（可产生危险省略） | **禁止部署**；仅隔离诊断 |

### 2.1 实现约束（实现阶段遵守，本阶段不改代码）

- D/E 必须通过 **显式开关** 实现，例如 `--v11-ablation no_emc|no_fallback`，写入 `run_meta.ablation`。  
- **禁止**通过改 tasks/Eval 伪装消融。  
- D/E 不得静默覆盖 C 的 run 目录；输出根目录必须独立（见 §4）。  
- B 组继续用 `run_p1.py`，避免与 v11 runner 漂移。

### 2.2 D 的精确定义

```text
plan.files = 每个 workspace *.py 一条 EXPAND
不做 R1/R2/R3/R4 选择
不做 visibility veto / REUSE_KV
```

隔离 EMC 贡献：C−D 的 ESR/TPSE 差 = 控制器选择 + 省略路径的联合效应（与回退耦合时见 §2.3）。

### 2.3 E 的精确定义与风险

```text
与 C 相同 EMC 计划
但 assemble 在 action=REUSE_KV 时跳过 O′，直接省略
不升级 EXPAND；不设 min_visible 之外的安全网（R3 仍可保留或按实现说明固定）
```

**预期风险（F 预注册）**：空/盲上下文 ↑、NO_EDIT ↑、危险省略（VSO 计数为 0 且省略发生）↑。  
E 的结果 **不得** 写入“推荐配置”；报告中必须标注 `UNSAFE_DIAGNOSTIC`。

## 5. 指标（全部组）

### 5.1 主指标

| 指标 | 定义 |
| --- | --- |
| ESR | 两步 eval_success 均为 1 的 episode 比例 |
| TPSE | Σ(prompt+completion) / 成功 episode |
| Input/Output Tokens | API 计数 |
| Latency | t_model_ms；另记 t_step_ms |

### 5.2 V1.1 系特有（C/D/E；A/B 为 N/A 或 0）

| 指标 | 定义 | 计算来源 |
| --- | --- | --- |
| 目标文件可见率 | 指令/闭包点名的文件出现在当步 context FILE 块的比例 | instruction ∩ project basenames vs context.txt |
| 检索成功率 RSR | plan.need=1 且 plan 内文件均出现在注入上下文或 O′ 证明省略的比例 | injection_audit |
| 危险省略次数 | 发生 REUSE 省略且 VSO=0，或省略后目标文件不可见 | assemble_audit + context |
| 回退次数 | fallback_events（O′ 失败升 EXPAND） | result / ledger |
| VSO | verified_safe_omission 文件数 | result |
| EMC 规则分布 | R0–R4 / veto 命中计数 | audit.rules |
| 失败原因分层 | 见 `v1.1.1_failure_attribution.md` 五类 | response + eval + audit |

### 5.3 账本

每步：`cost_index_ms, cost_route_ms, cost_assemble_ms, injected_chars, omitted_chars_est`。  
**禁止**只报 omitted_est 而不报失败步 token。

## 6. 预注册比较与判定（看到结果前锁定）

设 ESR/TPSE 下标为组名。

### 6.1 EMC（C vs D）

- **EMC 有价值（描述性）**：`ESR_C ≥ ESR_D − 0.05` 且 `TPSE_C ≤ TPSE_D`。  
- **EMC 有害**：`ESR_C < ESR_D − 0.10`。  
- 中间：记为“不确定”，扩大 R 或分层任务报告，不改阈值。

### 6.2 安全回退（C vs E）— 诊断性

- **回退必要（预期）**：`危险省略_E > 危险省略_C` 且  
  （`NO_EDIT_E ≥ NO_EDIT_C` 或 `ESR_E < ESR_C − 0.05`）。  
- **回退过度保守（意外）**：`ESR_E > ESR_C + 0.10` 且危险省略_E 仍低 → 回顾 O′ 是否误伤（F）。  
- **禁止**因 E 的 TPSE 更低就推荐关闭回退。

### 6.3 相对 A/B 的背景线（非消融门禁，报告必附）

沿用 `v1.1_experiment_protocol.md` §6：C 相对 B 非劣 Δ=0.10；C 相对 A 的 TPSE 门禁 δ=0.05。  
**在 24×R=3 上若仍不满足 TPSE 门禁，结论写“效率未证实”，不得写架构有效。**

### 6.4 多重比较

消融以效应量 + 分层任务表为主；不做“挑一个显著”的叙事。R=3 时 **不做** 复杂显著性包装。
