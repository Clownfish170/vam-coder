## 4. 样本量、重复、把握度限制

| 批次 | 范围 | 臂 | R | 约请求 |
| --- | --- | --- | --- | --- |
| P0 | 8 任务子集\* | D,E,F,G,H | 1 | 80 |
| P1 | 24 任务 | A,B,D,E,F,G,H | 3 | **1008** |
| P2 可选 | 24 | C | 3 | 144 |

\*RUR02, RUR03, DEL01, DUP01, CFD01, STM02, RFS01, IRR01。

**把握度限制（必须写入报告）**：

- 24 任务 × R=3 → 每臂 72 episodes；ESR 标准误量级约 \(\sqrt{p(1-p)/72}\approx 0.05\)–\(0.06\)，**对 5–10pp 非劣界检验把握度有限**。  
- 本设计偏向 **效应量 + 区间 + 配对一致性**，**不保证**传统 α=0.05 非劣试验把握度。  
- 不得在 CI 宽或配对不一致时宣称“统计意义上的非劣”；只可写“点估计满足预注册门禁，区间较宽”。

**排除与 Token 口径（r2.1）**：HTTP 错误同 rep 重跑一次；仍错则 ESR=fail；不删任务；不覆盖旧 run。  
**重试 Token**：同 episode 内重试仍属同一 episode，**累计全部实际请求的 API token** 进 \(T(e)\)/TPAE/FETC（与计费口径一致）。  
**FETC 口径交叉引用（r2.1）**：\(\mathrm{FETC}_{total}\)、\(\mathrm{FETC}_{mean}\)（含 \(N_{fail}=0\) 时 mean=NA）的计算定义以 **`v1.2_method_formulation.md` §1.3** 为准；本预注册 §4 的重试 Token 累计规则与 method 中 \(T(e)\) 统一，冲突时以两文档共同冻结的口径为准，不得另立第三定义。

## 6. 预注册判定（正式实验前冻结）

### 6.1 非劣界依据（r2）

| 阈值 | 值 | 选择依据（设计判断，非事后） |
| --- | --- | --- |
| ε vs D | **0.10** | 1.5B + seed0 仍存在任务级抖动；V1.0→V1.1 曾见 ±25pp 级任务翻转；0.10 允许机制改进伴随小幅回退，又避免“任意差都算非劣”。 |
| ε vs A | **0.15** | memory_off 为全源上限参考；更宽以检测“严重伤害”而非宣称等同。 |
| TPSE 门槛 | **5%** | 覆盖 harness 计数噪声与短 episode 量级；低于 5% 在 72 eps 上易被单任务支配，**不具可操作性**。 |
| TPAE 附加 | ≤1.05×ref | 防早失败假优势（见 method §1.3） |

### 6.2 门禁（点估计 + 区间纪律）

相对 **D**：

\[
\mathrm{ESR}_E\ge\mathrm{ESR}_D-0.10
\]

相对 **A**（伤害检测）：

\[
\mathrm{ESR}_E\ge\mathrm{ESR}_A-0.15
\]

效率（相对 D，且 ESR 点估计门禁通过）：

\[
\mathrm{TPSE}_E\le0.95\cdot\mathrm{TPSE}_D
\quad\land\quad
\mathrm{TPAE}_E\le1.05\cdot\mathrm{TPAE}_D
\]

宣称相对 A 降本时另需：

\[
\mathrm{TPSE}_E\le0.95\cdot\mathrm{TPSE}_A
\land \mathrm{ESR}_E\ge\mathrm{ESR}_A-0.15
\land \mathrm{TPAE}_E\le1.05\cdot\mathrm{TPAE}_A
\]

**统计宣称纪律**：

- 报告 Wilson 95% 区间（ESR）为 **补充**。  
- 若 \(\mathrm{ESR}_E-\mathrm{ESR}_D\) 的点估计 ≥ −ε 但区间大量落在 −ε 以下，**不得**写“已证实非劣”；只写“点估计通过预注册门禁，把握度不足”。  
- 正式结论句式预注册为：  
  - “满足预注册点估计门禁” / “未满足”；  
  - 避免无检验的 “statistically non-inferior”。

### 6.3 安全

DHO=0；ISR=0；RSR≥0.95（must 步）。

### 6.4 消融方向（描述性）

| 比较 | 支持有用的模式 |
| --- | --- |
| E vs F | TPSE_E<TPSE_F 且 ESR 不差于 F−0.05 → 细粒度非目标有价值 |
| E vs G | ESR 不差且 TPAE/TPSE_E<TPSE_G → 任务感知有价值 |
| E vs H | ESR_H≤ESR_E−0.05 → Digest 可能必要；ESR_H≥ESR_E 且 TPAE_H≤TPAE_E → Digest 可删（采纳负结果） |

## 7. 配对 Bootstrap 与任务级报告（r2）

### 7.1 任务配对 Bootstrap（r2.1）

- **抽样单位**：`task_id`；每次抽中一个 task，**保留该 task 下全部 R 次 rep 的全部 episode**（不把 72 个 episode 当独立样本重采样）。  
- 两臂对齐：同一 `task_id`（及同 rep 集合）配对。  
- 统计量：\(\Delta\mathrm{ESR}\)、\(\Delta\mathrm{TPAE}\)、\(\Delta\mathrm{TPSE}\)（TPSE 见下零成功规则）。  
- 重采样：有放回抽 task，\(B=10000\)，bootstrap seed=**20261102**。  
- 输出：点估计、Bootstrap 95% CI；**不**据此改门禁。  
- 与 Wilson 区间 **并列**；冲突时以预注册点估计门禁为准并披露。

**TPSE 分母为零（r2.1）**：

- 若某 Bootstrap 样本中某臂成功 episode 数 = 0 → 该臂 **TPSE = NA/∞**（**不得**记 0）。  
- \(\Delta\mathrm{TPSE}\) 在该样本记 **NA**。  
- 必须报告：**无定义 TPSE 的 Bootstrap 样本比例**；若比例 > 0，不得只报有限样本 TPSE 区间而不披露该比例。  
- 同时报告 **TPAE** 区间作为成本比较的稳定替代。

### 7.2 任务级成功率

每任务：ESR_arm(task)、ΔESR vs D/A；热图或表；标注 8 子集。  
分层（S/D/M，见 r1 §7）仅解释，不改主判定。

### 8.1 依赖闭包深度 \(d=2\) 冻结（v1.2-r2.1 P0.1 参数冻结补充）

**正式实验配置**：依赖闭包深度 **\(d=2\)**  
（must_full 含 \(\mathrm{dep}_{\leq d}^{+}(\mathrm{edit\_targets})\cup\mathrm{callers}_{\leq d}(\mathrm{targets})\)）。

**冻结依据（P0.1 全任务无模型 Dry-run）**：

1. 覆盖完整 **24** 个 V1.0 任务；  
2. 臂 E/F/G/H 共 **192** 条 injection 审计行（24×4×2 步）；  
3. **API 请求数 = 0**（无模型 dry-run）；  
4. must_full 规模（E 臂 step1，n=24）：mean/median/max/P90 = **2.04 / 2 / 4 / 3**；  
5. **over_kmax = 0**；  
6. **over_budget = 0**；  
7. **INSUFFICIENT = 0**；  
8. **v1_CLS01**：依赖链 `mid→low`、`high→mid`；自 `low.py` 出发 d=1 仅覆盖 `low,mid`，**d=2 才覆盖 `high`**；  
9. d=2 下 must_full 最大仍为 **4**（CLS02），无闭包爆炸。

证据路径（工作区，未 commit）：

- 报告：`p1/results/v1.2_p01_report.md`  
- 审计 JSON：`p1/results/v1.2_p01_audit.json`  
- Run：`p1/results/runs/v12_p01_dryrun_24tasks_EFGH_full/`

**限定结论（必须遵守）**：

- \(d=2\) 的冻结 **仅**表示：在 **当前 V1.0 24 任务集** 上，其 **工程适用性**（must 规模、预算、窗口、E/F/G/H 一致性、深度-2 链覆盖）得到 P0.1 支持。  
- **不得**声称：  
  - \(d=2\) 对任意代码仓库普遍最优；  
  - \(d=2\) 在所有任务上均优于 \(d=1\)；  
  - P0.1 已证明模型准确率提升；  
  - P0.1 已证明 Token 或 Prefill 效率提升。  

本节 **不改变** v1.2-r2.1 架构定义、实验臂、ESR/TPAE/TPSE 门禁或统计方案；仅冻结闭包深度参数。
