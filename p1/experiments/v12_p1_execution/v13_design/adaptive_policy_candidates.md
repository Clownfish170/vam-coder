# V1.3 自适应 Full/Digest 策略候选

冻结不变式（任何策略必须满足）：

- EditTargets / CandidateFull **始终 FULL**，禁止 VP 省略  
- must_full 不降级；VP 失败请求前 INSUFFICIENT  
- 自适应 **仅** 决定：**相关非目标** → Full 或 Digest  
- 默认无额外 LLM 调用；不用执行结果回看  

E=Digest 基线、F=Full 基线均保留。

---

## 策略 A — 保守规则（推荐基线）

**规则**：默认相关非目标 = **Digest**；当且仅当满足 **高信息需求** 条件时升 **Full**。

**高信息需求**（须全部或明确子集，实现时钉死）：

1. 相关非目标文件含 **FunctionDef/ClassDef 实现体**，且  
2. 指令中出现 **该文件名或其符号**（词边界），**或** 该文件 ∈ EditTarget 的 dep 闭包（通常已是 must），**或**  
3. 同任务相关非目标中 **实现体文件数 ≥1** 且步骤为编辑步（本任务集恒为编辑步）。

**输入**：τ、索引、AST、dep 图（均执行前）。  
**输出**：related ∈ {DIGEST, FULL}。  
**成本**：O(files) 字符串+AST，微秒级。  
**误判**：漏升 Full → 类 CFD03；过升 → TPAE↑。  
**安全**：不触碰 ET/VP。  
**与 E/F**：默认=E；触发时=F。  
**可实现性**：现有 assemble 高层改 related 策略即可。

---

## 策略 B — 分级（低/高，不强行三档）

| 等级 | 条件（执行前） | related |
| --- | --- | --- |
| 低 | 无实现体需求信号（无指令命中且非 dep） | Digest |
| 高 | (指令命中文件/符号) **或** (实现体 + 编辑步 + 相关) | Full |
| 中 | — | **不设第三档**（无可靠依据） |

与 A 等价的二值化表述；中间档空缺。

---

## 策略 C — 成本约束

在预算 B 内：

1. 先保证 ET/C/must FULL（不可动）  
2. 相关非目标按 **信息分** 排序：`score = 2*指令命中 + 2*实现体 + 1*dep邻接`  
3. 分 ≥阈值 → Full，否则 Digest  
4. 若 Full 数 > Kmax_related（如 3）或超 est 预算 → 按分数降为 Digest  

**误判**：阈值任意；**安全**：同 A。  
**成本**：排序 O(n log n)。

## 对比

| | A 保守 | B 分级 | C 成本 |
| --- | --- | --- | --- |
| 默认倾向 | Digest | Digest 低 / Full 高 | 预算内 Full |
| 实现 | 最低 | ≈A | 中 |
| 1.5B 适配 | 稳 | 稳 | 可能过度 Full |
| 推荐 | **主候选** | 文档同 A | 可选开关 |

- 需要执行后标签、额外 LLM、或放松 VP 的策略。
