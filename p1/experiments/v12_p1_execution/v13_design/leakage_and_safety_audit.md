# V1.3 信息泄漏与安全审计

## 1. 泄漏边界（强制）

| 允许（执行前） | 禁止 |
| --- | --- |
| 指令 τ、文件列表、AST、dep 图、focus 元数据、parser 结果 | eval_success、最终 workspace、response、F_only 标签 |
| 索引 validity/hash | 用本 24 任务结果“调参后宣称独立验证” |

- 若在本 24 任务上探索规则 → 文档必须标 **exploratory design**。  
- 验证：**冻结规则 + 独立任务集**（或新项目快照），不得同集调参再报验证。  
- 不确定 → **保守 Digest 或对编辑相关升 Full**（安全优先，不因不确定省略 must）。

## 2. 安全不变式（V1.3 冻结）

| 规则 | 状态 |
| --- | --- |
| ET 始终 FULL | **冻结** |
| CandidateFull 始终 FULL | **冻结** |
| ET/C 不被 VP 省略 | **冻结** |
| must 不降级、不因预算截断 | **冻结** |
| VP 失败 → 请求前 INSUFFICIENT | **冻结** |
| 自适应只作用于相关非目标 Full/Digest | **本设计范围** |

任何无法满足上表的策略 → **不可采用**。
