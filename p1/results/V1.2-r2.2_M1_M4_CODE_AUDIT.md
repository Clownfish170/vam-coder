## 6. 关键缺陷：INSUFFICIENT **未**阻止模型请求 — **FAIL**

**位置**：`p1/scripts/run_p1_v12.py` L254–266 置 `ctx.insufficient=True`；  
L300–307：`if dry_run: ... else: chat_completion(...)`。

**问题**：二次 verify 失败仅打标，**没有** `if ctx.insufficient: skip model`。

**规范要求**（r2.2 method / 你的验收点 3）：验证失败必须在 **请求前** INSUFFICIENT，**不得**发起模型请求。

**证据**：全文无 `if ctx.insufficient` 门闩（grep 仅 L255/372/396 写入与导出）。

**影响**：若 force_full 后仍缺 E/C 文件，真实模型路径会 **带缺口请求**（dry-run 未触发该路径）。

**定性**：实现与 r2.2 文档 **不一致** 的阻断缺陷 → 本项 **FAIL**。
